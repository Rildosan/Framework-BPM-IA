# Framework-BPM-IA
Repositório do Frameowork BPM:IA

## Sobre

Este repositório contém os artefatos produzidos
pela aplicação do Framework BPM:IA.

## Estrutura

O Framework BPM:IA está organizado em três grandes camadas:

- Camada de Interação Humana
- Camada Semântica de Processos de Negócio
- Camada de Inteligência Artificial e Analytics
## Camada Semântica

A Camada Semântica integra:
- Contexto
- Conhecimento de Processos
- Ontologia de Processos
- Documentação de Processos
- Dados de Processos
- Taxonomia
